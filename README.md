# codealpha_tasks_3
Basic frontend program
This repository contains the source code for my personal portfolio website, built to showcase my projects, skills, experience, and contact information. The goal of this site is to provide a professional online presence and make it easy for potential employers, collaborators, or clients to learn more about me.

# Features
Responsive Design – Works on desktops, tablets, and mobile devices.

Project Showcase – Highlighting key projects with descriptions and links to GitHub/live demos.

About Me – A short bio, skills list, and background info.

Contact Section – Easy way to reach out via a contact form or email/social links.

Dark/Light Mode – (Optional) Toggle theme for user preference.

# Technologies Used
Frontend: HTML, CSS, JavaScript (or React/Vue/etc.)

Styling: Tailwind CSS / Bootstrap / custom CSS

Hosting: GitHub Pages / Vercel / Netlify
